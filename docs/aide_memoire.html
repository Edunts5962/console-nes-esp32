Téléphone (manette8.html)

  • 🔗 CONNECTER : choisir la console. Rien dans la liste ? Diagnostic > SCAN BLE.
  • L'écran reste allumé tant que la manette est connectée.
  • MENU JEUX : tous les jeux, recherche, onglets Tous / Favoris / Récents, étoiles, carte Reprendre.
  • Curseur Volume de la console.
  • Dans les menus de la console : croix = curseur, A/START = jouer, SELECT = liste suivante.
  • Application : Chrome > ⋮ > Ajouter à l'écran d'accueil.

Sauvegardes

  • Pile (Zelda, Final Fantasy...) : gardée comme sur la cartouche.
  • Instantanées : 3 emplacements par jeu (menu pause).
  • Reprise : écrite en quittant le jeu ; « Reprendre » la relance.
  • Fichiers : dossier saves à côté des jeux (SD ou mémoire interne).

Portail web (Wi-Fi allumé dans Réglages)

  • Adresse : onglet Portail de la console (QR code). Sans box : réseau NES-WiFi, mot de passe nes12345, puis 192.168.4.1.
  • Envoyer des .nes ou des .zip ; rechercher, choisir plusieurs jeux, Doublons.
  • Réseau Wi-Fi de la box : changer de box sans recompiler.
  • Jeux écartés (plantage au démarrage) : Remettre ou Supprimer.
  • Maintenance > Mettre à jour le logiciel : fichier nes_emulator.ino.bin.

Le Bluetooth (téléphone) est coupé tant que le Wi-Fi est allumé ; il revient au lancement d'un jeu.

Un jeu qui fait redémarrer la console au lancement est mis de côté (dossier quarantaine), jamais effacé. Détails : LISEZMOI.txt, nes_emulator/README.md.
